# Software logo sources

Retrieved October 11, 2026. Marks identify software used in the portfolio and résumé. Original image bytes and SVG geometry are preserved.

- OpenFOAM: original logo from [the official site](https://www.openfoam.com/), `https://www.openfoam.com/themes/bs4esi/img/openfoam-logo.png?v20210416`.
- Ansys, Siemens, FreeCAD, Python, Dassault Systèmes: [Simple Icons source SVGs](https://github.com/simple-icons/simple-icons/tree/dc7b10662a0a2cfdfc9305e2a2b06c023c30724a/icons), pinned at `dc7b10662a0a2cfdfc9305e2a2b06c023c30724a`; their [metadata](https://github.com/simple-icons/simple-icons/blob/dc7b10662a0a2cfdfc9305e2a2b06c023c30724a/data/simple-icons.json) cites each vendor's official brand source. Included CC0 license.
- Official sources: Ansys https://www.ansys.com/about-ansys/brand; Siemens https://siemens.com; FreeCAD https://fpa.freecad.org/handbook/process/logo.html; Python https://www.python.org/community/logos/; Dassault Systèmes https://www.3ds.com.

Employer artwork reuses the sources in `assets/company-logos/SOURCES.md`. Software associations come from verified Experience/résumé text. General résumé skills are not assigned to employers without source evidence.
