# Stage06 evidence package

Start with [Presenter-Guide.html](Presenter-Guide.html) for a 10–15 minute walkthrough or [Job-Requirement-Matrix.html](Job-Requirement-Matrix.html) for thirteen expandable requirement rows. [Study-Requirements.md](Study-Requirements.md) defines chosen numeric limits and evidence rules.

The test plan, interface record, sensors, test matrix, raw CSV template and uncertainty budget form the planned hardware execution package. Design decisions, qualitative risk/FMEA, standards applicability and an unapproved review checklist document the proposed lifecycle. Completion-Boundaries.md lists the actual physical evidence still unavailable.

The synthetic correlation is an independent workflow demonstration, not measured calibration of the actual five-terminal assembly. No physical data is present. Download the full project source/results package from the guided website to reproduce numerical work.
