# Standards applicability and verification references

Reviewed: 24 October 2026. This is an **applicability assessment**, not a declaration of certification, qualification or regulatory approval. The real vehicle/system authority must select contractual requirements, current editions, equipment categories, severities, tailoring and acceptance criteria.

| Reference | Supported use in this study | Boundary / action before hardware qualification |
|---|---|---|
| [NASA GSFC-STD-7000, revision B catalog](https://standards.nasa.gov/standard/GSFC/GSFC-STD-7000) | Environmental-verification planning concepts and a structured test/analysis program. The official catalog currently lists B active. | Written for GSFC flight programs/payloads; not automatically applicable to a HAPS aircraft. Select and justify tailoring rather than copying test levels. No GEVS compliance claimed. |
| [RTCA DO-160 public overview](https://www.rtca.org/do-160/) | Candidate framework for environmental evaluation of airborne equipment. | Public page names DO-160G while also displaying an older planned DO-160H publication date. Resolve current controlled edition and intended categories directly with the authority/publisher before deriving a test specification. Detailed standard not used to claim a category or pass. |
| [NIST TN 1297](https://www.nist.gov/pml/nist-technical-note-1297) | Type A/Type B uncertainty, combination and reporting vocabulary for the test plan. | Does not supply our numerical sensor uncertainties, thermal acceptance thresholds or qualification requirements. |
| [NASA thermal-control overview](https://www.nasa.gov/smallsat-institute/sst-soa/thermal-control/) | Reference concepts for radiation, contacts, straps, insulation and active/passive control trade studies. | Spacecraft context cannot justify neglecting HAPS convection or treating spacecraft insulation performance as a measured HAPS property. |

The ECSS thermal-analysis handbook is a candidate future reference; its full text was not reviewed in this closure package and no ECSS compliance claim is made. Use an accessible controlled copy and record edition/applicability before citing normative clauses.

Qualification must separate operating, non-operating/survival, storage, altitude, temperature cycling and functional performance. A chamber run, numerical mesh check or synthetic correlation is not a substitute for the applicable product-level verification program.
